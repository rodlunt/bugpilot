Tab icon candidates

Recraft-generated ladybird glyphs, cleaned to a single currentColor path (viewBox kept, fixed fills and sizes stripped). Each is shown at 20, 36 and 96px on paper and on white, plus inside a mock 36px tab. Tick the one to ship and leave comments in the box. candidate-1.svg is the current live default in DEFAULT_TAB_ICON; the owner found it too clean, so sketch-1 to sketch-4 are a second round in a hand-drawn ink style with deliberately imperfect, wobbly linework. Nothing here is wired into the widget beyond the existing default.

To ship a pick, paste the chosen file's markup into DEFAULT_TAB_ICON in widget/src/icon.js, or pass it per host as BugPilot.init({ icon }).
